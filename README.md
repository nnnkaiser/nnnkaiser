# Nico Kaiser

PhD candidate at the University Medical Center Hamburg-Eppendorf (UKE). I build image-analysis pipelines for tissue: registration, segmentation and multimodal integration of 3D light-sheet microscopy, histology and multiplex immunofluorescence. Before my PhD, I spent three and a half years as an AI software engineer in medical imaging.

Most of my code lives in organisation repositories rather than on this profile:

- **[biocontext-ai](https://github.com/biocontext-ai)**: member of the maintainer team of BioContextAI, a community hub of MCP servers for agentic biomedical AI ([my pull requests](https://github.com/biocontext-ai/knowledgebase-mcp/pulls?q=is%3Apr+author%3Annnkaiser))
- **[complextissue](https://github.com/complextissue)**: GitHub organisation of the Complex Tissue lab (Prof. Victor Puelles)
- **In preparation:** open-source releases of a batch registration and quality-control tool for iterative multiplex imaging, and of a deep-learning package for podocyte quantification
